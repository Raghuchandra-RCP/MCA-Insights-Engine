# 🏢 MCA Insights Engine - Portable Version

**Advanced Corporate Data Analytics Platform**

## 🚀 **Quick Start**

### **Windows:**
1. Extract this ZIP file
2. Double-click `run.bat`
3. Open browser to `http://localhost:5000`

### **Mac/Linux:**
1. Extract this ZIP file
2. Run: `chmod +x run.sh && ./run.sh`
3. Open browser to `http://localhost:5000`

## 📋 **Requirements**
- Python 3.11+ (download from python.org)
- Internet connection (first time only)

## 🎯 **Features**
- 📊 Dashboard with real-time statistics
- 🔍 Advanced company search
- 📈 Change analysis and tracking
- 🎯 Data enrichment system
- 🤖 AI-powered chatbot
- 🔌 REST API endpoints

## 📊 **Sample Data**
- 100 companies from 5 states
- Complete change tracking
- Enriched data with sectors and directors

## 🛠️ **Manual Setup**
If automatic setup fails:
1. `pip install -r requirements-simple.txt`
2. `python data_integration.py`
3. `python mca_data_processor.py`
4. `python flask_dashboard.py`
